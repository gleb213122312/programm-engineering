## Самостоятельная работа №5
### Составьте программу, результатом которой будет вывод в консоль:
hello world
hello
hello world
hello
hello world
hello
hello world
hello
hello world
hello
hello world

```python
string = 'hello'
values = [0, 2, 4, 6, 8, 10]
counter = 0
while ' world' not in string:
    memory = string
    if counter in values:
        string+= ' world'
    print(string)
    if counter <10:
        string = memory
    counter +=1
```
### Результат:
![](pic/sam5.png)

## Вывод:
Программа начинает со строки "hello" и счётчика 0.
Цикл выполняется до тех пор, пока в строке не появится подстрока " world".
При значениях counter из списка [0, 2, 4, 6, 8, 10] к строке временно добавляется " world", и эта версия выводится.
Если counter < 10, строка сразу после вывода сбрасывается обратно к "hello".
Начиная с counter = 0 до counter = 9, программа всегда выводит "hello world", но затем возвращает строку в исходное состояние.
На шаге counter = 10 строка "hello world" уже не сбрасывается. Условие цикла становится ложным, и программа завершает работу.
